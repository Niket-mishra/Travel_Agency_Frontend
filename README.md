# Travel_Agency_Frontend

**A modern, responsive front-end template for travel agencies and tour operators.**

## Overview ✨
Travel_Agency_Frontend is a clean, lightweight starter template focused on attractive visuals, fast performance, and easy customization. Built with semantic HTML5, modular CSS, and vanilla JavaScript, it provides reusable components for hero sections, blog posts, and booking-ready layouts—perfect for prototypes, demos, or production sites.

## Features ✅
- Responsive layouts and accessible markup
- Reusable components for hero, blog, and post pages
- Lightweight JavaScript for simple interactivity
- Easy-to-tweak styles in `custom.css`
- Image assets in the `images/` folder

## Tech Stack ⚙️
- HTML5 • CSS3 • JavaScript
- Bootstrap 6 (utility-first layout and grid)

## Project Structure 🔧
```
├─ Index.Html       # Homepage / hero area
├─ blog.html        # Blog listing
├─ post.html        # Single post template
├─ custom.css       # Project styles
├─ script.js        # JavaScript behaviors
├─ images/          # Media assets
└─ README.md        # This file
```

## Getting Started 💡
1. Clone the repo:
   ```bash
   git clone https://github.com/Niket-mishra/Travel_Agency_Frontend.git
   cd Travel_Agency_Frontend
   ```
2. Open `Index.Html` in your browser or serve the folder with a static server (e.g., `python3 -m http.server 8000`).

## Customization Tips ✍️
- Update visuals in `images/` and modify `custom.css` for brand colors and typography.
- Tweak interactive behaviors in `script.js` or replace with your preferred framework.
